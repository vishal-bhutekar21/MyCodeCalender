01. Introduction

Code Calendar ("we", "our", or "us") is a developer productivity and competitive programming aggregator application designed and maintained by Vishal Bhutekar.

This Privacy Policy explains how our Android mobile application collects, uses, and protects your information when you download, install, and use Code Calendar (package name: com.vishal.codecalendar) from the Google Play Store.

02. Information We Collect

A. Public Competitive Programming Handles:

When you connect platforms such as LeetCode, Codeforces, CodeChef, AtCoder, or GitHub, we store your public handle locally to query public API endpoints. We never ask for or store passwords.

B. Local App Preferences & Daily Streak:

Theme choices, notification reminder offsets (e.g. 15 minutes prior), and daily login streak dates are persisted in your device's local storage.

C. Non-Personal Technical Information:

Network connectivity status is checked locally to seamlessly switch between live syncing and offline cached contest schedules.

03. Android Permissions Disclosure

Permission Type Purpose / Rationale
POST_NOTIFICATIONS Runtime (Android 13+) Deliver 15-minute contest countdown reminders configured by the user.
SCHEDULE_EXACT_ALARM Alarm API Schedule precise reminder alarms before live competitive programming contests begin.
WRITE_CALENDAR & READ_CALENDAR Optional / Runtime Allow users to export tracked contests directly to their native Google / device calendar with 1 tap.
INTERNET & ACCESS_NETWORK_STATE Normal Fetch up-to-date contest schedules from public competitive programming APIs.
RECEIVE_BOOT_COMPLETED Normal Reschedule registered contest reminder alarms after device restart.
